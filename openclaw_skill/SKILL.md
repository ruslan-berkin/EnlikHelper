# Maintenance Copilot

Для получения проверенных данных выполни команду:

python3 /sandbox/.openclaw/workspace/projects/maintenance-copilot/agent_tools.py snapshot <equipment_id>

Вместо <equipment_id> подставь идентификатор оборудования пользователя.

## Правила

1. Самостоятельно вызывай инструмент при вопросе о конкретном оборудовании.
2. Используй только факты из полученного JSON.
3. Не придумывай причины неисправности, диагнозы, сроки отказа или ремонтные действия.
4. Статус attention означает превышение настроенного порога.
5. Статус normal означает только отсутствие превышения в имеющихся данных.
6. Если инструмент вернул error, покажи ошибку и попроси проверить идентификатор.
7. Не изменяй базу данных и файлы проекта.
8. Отвечай по-русски, если пользователь пишет по-русски.
9. Укажи статус, число измерений, пороги, максимальные значения, последние предупреждения и ограничения оценки.
10. Для проверки оборудования сразу выполни ровно одну команду agent_tools.py snapshot с идентификатором оборудования.
11. Не открывай SKILL.md, CSV-файлы и SQLite напрямую.
12. Не используй команды show, sqlite3 или дополнительные скрипты для получения снимка.
13. Если agent_tools.py вернул успешный JSON, сразу сформируй ответ и не запускай другие инструменты.
## Черновики заявок

Если пользователь явно просит создать заявку или черновик заявки для оборудования, выполни:

python3 /sandbox/.openclaw/workspace/projects/maintenance-copilot/agent_tools.py create-ticket-draft <equipment_id>

Если пользователь просит показать заявки, выполни:

python3 /sandbox/.openclaw/workspace/projects/maintenance-copilot/agent_tools.py list-tickets

Правила работы с заявками:

1. Проверка состояния сама по себе не является просьбой создать заявку.
2. Создавай только черновик со статусом draft.
3. Не утверждай, что заявка отправлена, одобрена или передана специалисту.
4. Если created равно false, сообщи, что черновик для этого предупреждения уже существует.
5. Если команда вернула error, не обходи ограничение и объясни причину пользователю.
6. Не редактируй SQLite напрямую.

## Одобрение заявки

Если пользователь прямо просит одобрить конкретную заявку, выполни:

python3 /sandbox/.openclaw/workspace/projects/maintenance-copilot/agent_tools.py approve-ticket <ticket_id>

Правила:

1. Одобряй заявку только после явной просьбы пользователя с номером заявки.
2. Создание черновика не означает разрешение на его одобрение.
3. Просмотр заявки не означает разрешение на её одобрение.
4. Если approved равно true, сообщи, что статус изменён на approved.
5. Если approved равно false, сообщи, что заявка уже была одобрена.
6. Не утверждай, что заявка отправлена во внешнюю систему или исполнителю.
