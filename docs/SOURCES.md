# EnlikHelper: источники инструкций

## ABB Low Voltage Motors Manual

- Производитель: ABB
- Документ: *Manual for Low Voltage Motors — Installation, operation, maintenance and safety manual*
- Версия в PDF: 01-2009, документ 3GZF500730-85
- Официальная страница библиотеки ABB: https://www.abb.com/global/en/areas/motion/motors-generators/low-voltage-motors/iec-low-voltage-motors/iec-lv-manuals
- Прямая копия, использованная для локального поиска: https://library.e.abb.com/public/70a30c0d0999feacc1257dd90035cf07/LVStdMotorsManual_EN_01_2009.pdf

Инструкция используется как демонстрационный источник знаний для `MOTOR-01`. Идентификатор `MOTOR-01` пока не связан с конкретной моделью двигателя, серийным номером или паспортом оборудования. Поэтому найденные фрагменты помогают сформировать список проверок и ссылку на страницу, но не заменяют руководство именно для установленного двигателя.

Файл PDF хранится локально в `data/manuals/` и намеренно не включается в Git-репозиторий. В Git публикуется только ссылка на официальный источник и описание ограничения демонстрационного сопоставления.
