# EnlikHelper: источники инструкций

## ABB M2BAX 90SA 4

- Производитель: ABB
- Продуктовый код ABB: 3GBA092110-ADT
- Основание выбора для demo-данных: модель с 4 полюсами рассчитана примерно на 1500 об/мин, что соответствует показаниям `MOTOR-01` около 1500 RPM.
- Официальная карточка продукта: https://www.abb.com/global/en/products/3gba092110-adt
- Официальная инструкция серии M2BAX/M2: https://library.e.abb.com/public/b82f3eb5553240c5a92c8358a22492ba/3GZC911A00128_enzh_H_M2%20series%20three-phase%20asynchronous%20motor%20installation%2C%20operation%2C%20maintenance%20and%20safety%20manual.pdf

`MOTOR-01` теперь привязан к этой реальной модели как демонстрационный экземпляр. Это не подтверждает, что физический двигатель пользователя действительно ABB M2BAX 90SA 4: для этого нужно сверить шильдик. Пороговые значения и измерения в проекте остаются демонстрационными.

PDF хранится локально в `data/manuals/` и намеренно не включается в Git-репозиторий. В Git публикуется ссылка на официальный источник и описание сопоставления.
